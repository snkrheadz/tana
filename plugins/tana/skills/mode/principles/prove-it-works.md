# Prove it works
Open when: you are about to say a task is done.

Covered by `../pillars/sounding.md` (proxies that do not count, read the real value) and the closing rules in the mode skill.

Nuance: indirect signals feel cheaper than looking, and acting on a wrong inference costs more than the look. Check liveness by asking the process, read the value itself, not a copy. If a check fails, doubt your way of observing before you doubt the system. Best proof is a script that reruns the same comparison; keep its output where the reviewer can see it, and commit it only when the trail must be auditable.
