# Subtract before you add
Open when: starting a change in an area with dead code or unused options, or about to polish before the core works.

Covered in `../pillars/light-tackle.md` (before you add, subtract; things that do not earn their place). Extras:

- Leave the design a little simpler and more capable than you found it, behind the same or smaller surface.
- Reach the minimum first and polish after.
- Build for observed use, with no validators or parsers beyond what the spec asks.
- Trim prompts and docs the same way: delete redundant instructions, and delete a reference with nothing new rather than keeping a stub.
