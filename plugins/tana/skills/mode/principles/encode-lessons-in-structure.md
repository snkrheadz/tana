# Encode lessons in structure
Open when: you are about to write the same instruction twice, or a correction keeps coming back.

Repeated text is a symptom. If a test, type, lint rule, hook, or script can enforce the rule, build that and let it be the only home. When structure fixes it, skip the extra prose.

Only a lesson that truly needs judgment stays as words. Then make it hard to miss and attach an example of the failure.

The ranking of homes, and how to move a rule into a check, is in `../pillars/log-the-catch.md`. Follow it rather than restating it here.
