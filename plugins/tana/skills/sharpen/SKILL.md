---
name: sharpen
description: Make a task deeper rather than bigger, then rewrite the prompt to ask for that. Use for /tana:sharpen or "make this prompt better", "what would an expert do here".
disable-model-invocation: true
---

Take the task I gave and aim for depth, not scope. Before rewriting, answer four things:

1. What would an expert in this field do that my prompt does not ask for?
2. What raw material would they start from, rather than a digest someone already made?
3. Which methods and tools would they use, by name?
4. What outside source could confirm the result is right, other than you or me?
   (`../mode/pillars/sounding.md` has the idea.)

Then rewrite my prompt to ask for exactly that. Keep it about the same size. Where a
choice belongs to me, leave it open and mark it, instead of settling it for me.
