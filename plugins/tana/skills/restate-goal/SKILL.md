Say back, in your own words, what you think I want and the problem behind it.

1. Write the goal in one or two sentences, then the underlying problem in one.
2. Name what would count as done. If you cannot, say that is the gap.
3. List any assumptions you made, each marked as one I should correct if wrong.
4. Ask nothing else. Do not start work. Wait for me to confirm or fix it.
